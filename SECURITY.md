## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it via the following method:

* **Email:** otony7033@gmail.com
* **Private Vulnerability Reporting:** Use GitHub's private reporting tab if available on the repository.

Please do **not** disclose security vulnerabilities publicly until they have been addressed and a patch has been released. You will receive a response within 48 hours.
